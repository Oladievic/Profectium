# Profectium

Платформа обратного подбора ИТ-специалистов: кандидат проходит оценку, работодатель выбирает специалистов по категории и навыкам и отправляет предложение.

**Работающий сайт: [profectium.oladievic.workers.dev](https://profectium.oladievic.workers.dev).** Можно зарегистрироваться с вымышленным email или нажать «Попробовать без регистрации».

[Полная документация в Word](docs/Profectium_Полная_документация.docx) — руководство обеих ролей, установка, архитектура, данные, API, интеграции, тестирование и соответствие ТЗ. Редакция от 11 октября 2026 года.

Публичная серверная версия поддерживает регистрацию кандидата и работодателя с вымышленным email без подтверждения почты. Зарегистрированные пользователи работают в общей базе; кнопка «Попробовать без регистрации» открывает отдельное демопространство с тестовыми данными и переключением ролей. Тестовая организация «Орбита» сохранена.

Публичный сайт использует восемь страниц редизайна из `design/`, подключённых к API и базе `platform/`. Кабинеты, тесты, профили, вакансии, приглашения и REST-ключи сохраняют данные на сервере. Поиск использует бесплатные локальные правила; формы вебхуков остаются демонстрационными и не отправляют события.

Для локального запуска установите Node.js 24 с npm и распакуйте репозиторий целиком:

1. Один раз выполните `Setup-Profectium.cmd`: он установит зависимости и соберёт приложение.
2. Запустите `Start-Profectium.cmd`. Откроется редизайн с API и локальной базой на `http://127.0.0.1:5190`.
3. Зарегистрируйтесь или нажмите «Попробовать без регистрации». В демо можно менять роль и профиль кандидата.

После первой установки запуск работает без внешних ключей и входа в Cloudflare. Данные хранятся в `platform/.wrangler/redesign-state` и не синхронизируются с публичным сайтом. Окно сервера оставьте открытым; остановка — Ctrl+C. Единственный файл запуска — `Start-Profectium.cmd`.

Подробные команды: [ЗАПУСК.txt](ЗАПУСК.txt). Контракт API: [platform/public/openapi.json](platform/public/openapi.json).

Проверено 11.10.2026: сборка, TypeScript, ESLint, 15 серверных наборов `npm test`, авторизация и SQLite, 900 вариантов заданий. Дополнительно проверены действия страниц редизайна через реальный HTTP API: сохранение профиля, публикация, восстановление теста, серверная оценка, компания и вакансия, оффер между аккаунтами и повторный вход. Реальная доставка email и официальный API ФСП не подключены.

## Публичное размещение

Редизайн `design/` и серверная часть `platform/` развёртываются вместе напрямую в Cloudflare Workers Free + D1 Free. Сборка и команды выполняются из `platform/`:

```text
npm ci
npm run build
npx wrangler login
npx wrangler d1 create profectium
npm run cloudflare:prepare -- --account-id=<ID аккаунта> --database-id=<ID созданной базы>
npm run cloudflare:migrate
npm run cloudflare:deploy
```

Конфигурация конкретного аккаунта сохраняется только локально в `.cloudflare/`. Пароли и cookie не хранятся в исходниках. Публичный режим включает `PUBLIC_DEMO_AUTH=true`; подтверждение email не требуется. Перед выкладкой доступны `npm run cloudflare:check`, `npm run test:auth` и `npm run test:sqlite`. Контракт включает 134 операции на 113 путях, в том числе 5 операций самостоятельной авторизации.

Есть также переносимый вариант Next.js + SQLite: `npm run build:beget`, затем `npm run start:beget`. Для него задайте `PUBLIC_DEMO_AUTH=true`, `PROFECTIUM_PUBLIC_URL` и постоянный `PROFECTIUM_DATA_DIR`; его наличие не означает совместимость с бесплатным тарифом Beget. Локальная база и данные Cloudflare независимы.

В репозитории сохранены исходники, ресурсы, лицензии, миграции, тесты, конфигурационные примеры и инструкции. Секреты, локальная база, зависимости, сборки, ТЗ, промежуточные отчёты и временные рабочие папки исключены.
