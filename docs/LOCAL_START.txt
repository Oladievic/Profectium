PROFECTIUM — ЛОКАЛЬНЫЙ ЗАПУСК

Нужны Node.js 24 с npm и полностью распакованный репозиторий.

Первый запуск:
  1. Один раз выполните Setup-Profectium.cmd с доступом в интернет.
     Он установит зависимости и соберёт приложение.
  2. Запустите Start-Profectium.cmd из корня репозитория.
  3. Откройте http://127.0.0.1:5190, если браузер не открылся сам.
  4. Зарегистрируйтесь с вымышленным email без подтверждения почты
     либо нажмите «Попробовать без регистрации».

Запускаются восемь страниц интерфейса, API и локальная база.
В гостевом демо доступны переключение ролей и тестовые данные.
После первой установки повторный запуск не устанавливает пакеты.
Библиотеки и шрифты включены; внешний вход и ключи не нужны.

Данные сохраняются в platform/.wrangler/redesign-state между запусками.
Эта база не синхронизируется с публичным сайтом и не попадает в GitHub.

Другой порт или запуск без открытия браузера:
  Start-Profectium.cmd -Offline -NoBrowser -Port 5192
Из папки platform можно выполнить:
  node scripts/start-redesign.mjs --offline --no-browser --port 5192

Окно сервера оставьте открытым; остановка — Ctrl+C.
При ошибке сохраните текст из окна запуска. Если не найден Node.js,
установите Node.js 24 с npm и повторите запуск.
Если нет зависимостей, выполните Setup-Profectium.cmd.
Если порт занят, закройте прежний сервер или задайте свободный порт.
Не открывайте HTML двойным щелчком: интерфейсу нужен сервер.

Подробная инструкция: ЗАПУСК.txt в корне репозитория.
Авторство и условия использования: readme.md.

Публичный сайт: https://profectium.oladievic.workers.dev
Локальный запуск и публичный сайт используют независимые базы.
