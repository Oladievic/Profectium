PROFECTIUM — РЕДИЗАЙН С РАБОТАЮЩЕЙ БАЗОЙ

ГОТОВЫЙ САЙТ ДЛЯ ЖЮРИ
https://profectium.oladievic.workers.dev
Регистрация принимает вымышленный email без подтверждения; пароль — от 6 символов.
«Попробовать без регистрации» открывает демо с переключением ролей,
тестовыми специалистами и организацией «Орбита».
Публичный сайт работает на бесплатных Cloudflare Workers и D1.

ЛОКАЛЬНЫЙ ЗАПУСК
1. Установите Node.js 24 с npm, распакуйте весь репозиторий.
2. Один раз выполните Setup-Profectium.cmd. Интернет нужен для зависимостей.
3. Дважды нажмите Start-Profectium.cmd и дождитесь открытия браузера.
4. Адрес по умолчанию: http://127.0.0.1:5190

Запускаются новый интерфейс, API и локальная база. Вход в Cloudflare,
внешние ключи и подтверждение email не нужны. После установки зависимостей
локальный запуск работает без интернета. Библиотеки и шрифты включены.
В демо роль меняется в шапке, профиль кандидата — списком «Демопрофиль».

ОСТАНОВКА
Оставьте окно сервера открытым. Ctrl+C останавливает сервер.
Повторный запуск той же версии использует уже работающий экземпляр.
При занятом порте или изменившихся исходниках прочитайте сообщение;
закройте прежний сервер или выберите другой порт.

ДАННЫЕ
Локальная база: platform/.wrangler/redesign-state.
Она сохраняется между запусками и не попадает в GitHub.
Данные публичного сайта и локальной копии независимы.

ПАРАМЕТРЫ
  Start-Profectium.cmd -Offline -NoBrowser -Port 5192
Через терминал из папки platform:
  node scripts/start-redesign.mjs --offline --no-browser --port 5192

ПРИ ОШИБКЕ
Если Node.js не найден — установите Node.js 24 с npm и откройте терминал заново.
Если нет зависимостей — выполните Setup-Profectium.cmd.
Если браузер не открылся — откройте адрес из окна сервера вручную.
Не запускайте HTML двойным щелчком: интерфейсу нужен сервер.
Не закрывайте окно ошибки, пока не прочитали причину.

В этой версии поиск работает по бесплатным локальным правилам.
REST-ключи создаются и отзываются сервером. Формы вебхуков остаются
макетом без отправки событий. Проверка ФСП ID и почтовая доставка не подключены.
Полное руководство: docs/Profectium_Полная_документация.docx.
Авторство и условия использования: readme.md.
